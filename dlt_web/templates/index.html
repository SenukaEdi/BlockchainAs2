Task 1 — Digital Signature Authentication

Select a node, enter a new inventory record, and sign it with that node's RSA private key. All other nodes verify the signature.

New Record
How It Works

Step 1 — RSA keys derived: n = p×q, φ(n) = (p−1)(q−1), d = e⁻¹ mod φ(n)

Step 2 — Record hashed: H(record) = SHA-256 mod n

Step 3 — Signature: S = H(record)^d mod n

Step 4 — All nodes verify: S^e mod n == H(record)

Task 2 — Consensus Protocol (PBFT)

Enter a record and signature. All inventory nodes vote on whether to accept it. Requires 75% supermajority.

Consensus Input
PBFT Phases

Pre-prepare — Leader broadcasts signed record

Prepare — Each node verifies RSA signature independently

Commit — Each node casts ACCEPT or REJECT vote

Decision — ≥75% ACCEPT → record stored at all nodes

Task 3 — Multi-Signature Query & Secure Delivery

Query an item's quantity. All nodes jointly sign the result using the Harn identity-based scheme. The PKG encrypts the response with the Procurement Officer's RSA public key.

Query Request
Harn Multi-Signature Scheme

PKG issues s_i = ID_i^d_pkg mod n_pkg

Each node signs sig_i = (H(m) * r_i + s_i) mod n_pkg

Aggregate S = sum(sig_i) mod n_pkg

Verify S == (H(m)*R + sum(s_i)) mod n_pkg

Encrypt C = M^e_officer mod n_officer
