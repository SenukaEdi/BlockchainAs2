Task 1 — Digital Signature

The originating node signs the record: S = H(record)^d mod n. All nodes independently verify.

Task 2 — Consensus

Runs PBFT consensus on a pre-signed record. Needs ≥ 3 of 4 nodes to ACCEPT. Paste the signature from Task 1 output.

Task 1 + 2 — Full Record Lifecycle

Runs sign → verify → consensus → store in one step. Recommended for demonstration.

Task 3 — Multi-Signature Query

Officer queries an item. All nodes sign using Harn scheme. PKG aggregates, verifies, encrypts. Officer decrypts.
